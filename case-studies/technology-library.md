# Technology Library

## Problem

Public technology resources appear across multiple sources, often with repeated entries and inconsistent metadata. A team needs a searchable collection with traceable sources and downloadable results.

## Implementation

A functional Python pipeline reads GitHub and the official MCP Registry, saves raw responses, normalizes metadata and merges repeated identities while retaining source links. A Streamlit interface provides search, filters, record inspection and CSV/JSON downloads.

## Available materials

[Open the project](https://github.com/RuddiRodriguez/product-library-demo) for Python source, a saved public-data snapshot, a preview, setup instructions and checks.

## Relevance

Demonstrates data ingestion, cleaning, traceability, a lightweight staff-facing interface and reusable exports.

## Scope

A standalone demonstration, not a production deployment or a trained machine-learning model. Resource categories come from collection routes. Licence metadata is recorded for review; commercial-use rights are not verified.
